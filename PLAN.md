# Build Plan — `officeless-generate-pdf`

A plan for Claude Code to build a small monolithic Node.js service that renders
Tailwind HTML templates to PDF, base64-encodes them, uploads to the officeless
(jojonomic OOS) endpoint, and returns the object storage URL.

**Pipeline:** template → HTML (inlined Tailwind) → PDF (Puppeteer) → base64 → officeless upload → storage URL

---

## Constraints

- **Node.js >= 18**, ESM (`"type": "module"`), native `fetch` — do not add axios/node-fetch.
- **Monolith:** one deployable Express service. Split into small modules for readability, not microservices.
- **Dependencies — keep minimal:** `express`, `puppeteer` (runtime); `tailwindcss` (dev). Nothing else. No template engine (write a tiny `{{ var }}` interpolator by hand).
- **Tailwind is precompiled** with the Tailwind CLI into a static CSS file, then inlined into the HTML at render time. Do **not** use the Play CDN — it needs network + JS execution at render and makes server-side rendering slow and flaky.

---

## Target file structure

```
officeless-generate-pdf/
├── server.js              # Express entry, wires pipeline, POST /generate + /health
├── package.json
├── tailwind.config.js      # scans templates/ and src/
├── .env.example
├── .gitignore
├── README.md
├── src/
│   ├── input.css           # @tailwind base/components/utilities
│   ├── template.js         # load template, {{ interpolate }}, inline compiled CSS
│   ├── pdf.js              # Puppeteer render, shared browser, printBackground:true
│   └── officeless.js       # base64 upload → storage URL
├── templates/
│   └── invoice.html        # example Tailwind template with {{ placeholders }}
└── public/
    └── tailwind.css        # build output (gitignored, generated by build:css)
```

`node_modules/` and `public/tailwind.css` are generated — gitignore them.

---

## External contract — officeless upload (fixed)

- **Endpoint:** `https://api-oos.jojonomic.com/14/pmt/upload-file`
- **Auth:** `Authorization: Bearer <token>`
- **Content-Type:** `application/json`
- **Request body:**
  ```json
  { "content": "<base64>", "filename": "<name>" }
  ```
- **Response:** shape not yet confirmed. Read the storage URL from a configurable
  dot-path (default `url`). If the real response nests it (e.g. `data.url`),
  it must be overridable via an env var without code changes. Throw a clear
  error naming the path if the URL isn't found.

All officeless request details must be env-driven:

| var | default | required | meaning |
|-----|---------|----------|---------|
| `OFFICELESS_UPLOAD_URL` | — | yes | endpoint |
| `OFFICELESS_TOKEN` | — | yes | bearer token |
| `OFFICELESS_FILE_FIELD` | `content` | no | JSON field for base64 |
| `OFFICELESS_NAME_FIELD` | `filename` | no | JSON field for name |
| `OFFICELESS_URL_PATH` | `url` | no | dot-path to URL in response |

## Implementation steps

Do these in order. After each phase, run the matching verification before moving on.

### Phase 1 — Scaffold
- Create `package.json`: `type: module`, scripts `build:css`, `dev` (build css + `node --watch server.js`), `start` (`node server.js`). Deps `express`, `puppeteer`; devDep `tailwindcss`.
- Create `.gitignore` (`node_modules/`, `public/tailwind.css`, `.env`, `*.pdf`).
- Run `PUPPETEER_SKIP_DOWNLOAD=1 npm install` if Chromium can't download in the build env; otherwise plain `npm install`.
- **Verify:** `node --version` >= 18; `npm ls express puppeteer` resolves.

### Phase 2 — Tailwind
- `tailwind.config.js` with `content: ["./templates/**/*.html", "./src/**/*.js"]`.
- `src/input.css` with the three `@tailwind` directives.
- Add script `build:css`: `tailwindcss -i ./src/input.css -o ./public/tailwind.css --minify`.
- **Verify:** `npm run build:css` produces `public/tailwind.css` (should be small — only classes used in templates, purged).

### Phase 3 — `src/template.js`
- Export `renderTemplate(name, data)`.
- Read `templates/<name>.html`, run a tiny `{{ key }}` interpolator supporting dot-notation (`{{ invoice.number }}`), missing keys → empty string.
- Read + cache `public/tailwind.css`, inline it in a `<style>` inside a full HTML document, return the string.
- **Verify (script, run from project root):** render `invoice` with sample data; assert CSS is inlined (`.text-indigo-600` present), placeholders are replaced, and no `{{ }}` remains.

### Phase 4 — `src/pdf.js`
- Export `htmlToPdf(html, options)` and `closeBrowser()`.
- Launch **one** shared Chromium (`--no-sandbox --disable-setuid-sandbox`), reuse across calls via a cached promise.
- `page.setContent(html, { waitUntil: "networkidle0" })`, await `document.fonts.ready`, then `page.pdf({ format: "A4", printBackground: true, margin: {...} })`.
- **`printBackground: true` is mandatory** — without it Tailwind background colors/gradients drop from the PDF.
- Close the page in `finally`.
- **Verify:** if Chromium is available, render sample HTML and assert the buffer starts with `%PDF`. If Chromium can't be downloaded in this env, skip and note it — this is the only stage that needs the browser binary.

### Phase 5 — `src/officeless.js`
- Export `uploadToOfficeless(base64, filename)`.
- Read the env vars from the table above; build headers (`Content-Type: application/json`, `Authorization: Bearer` when token set).
- POST `{ [fileField]: base64, [nameField]: filename }`.
- On non-2xx: throw with status + body text.
- Extract the URL via the configurable dot-path; throw a clear error if absent.
- **Verify (mock server):** stand up a throwaway `http` server, point `OFFICELESS_UPLOAD_URL` at it, call the function; assert it received `content` + `filename`, the `Bearer` header, and that the returned URL matches the mock's response.

### Phase 6 — `server.js`
- Express, `express.json({ limit: "2mb" })`.
- `GET /health` → `{ ok: true }`.
- `POST /generate` body `{ template, data, filename?, upload? }`:
  - 400 if `template` missing.
  - render → pdf → base64.
  - if `upload === false`, return `{ filename, base64 }` (lets you test the render without a live endpoint).
  - else upload and return `{ filename, url }`.
  - 500 with `{ error }` on failure; log the error.
- Reuse one Chromium; close it on `SIGINT`/`SIGTERM`.
- **Verify:** boot server, `curl /health` → `{ ok: true }`; `POST /generate` with `{}` → 400 `template is required`.

### Phase 7 — Example template + docs
- `templates/invoice.html`: a Tailwind invoice using `{{ invoice.number }}`, `{{ company.name }}`, `{{ customer.name }}`, `{{ item.description }}`, `{{ invoice.total }}`, etc. Use flex/grid, background colors, a table.
- `.env.example` with the real endpoint prefilled and `OFFICELESS_TOKEN` blank.
- `README.md`: stack, layout, setup (`npm install` → `npm run build:css` → copy `.env` → `npm start`), the `/generate` curl example, the officeless config table, and the gotchas below.

## End-to-end verification

```bash
npm install
npm run build:css
cp .env.example .env          # set OFFICELESS_TOKEN
npm start
# in another shell:
curl -X POST http://localhost:3000/generate \
  -H "Content-Type: application/json" \
  -d '{"template":"invoice","upload":false,
       "data":{"invoice":{"number":"1042","date":"2026-07-22","total":"$1,250.00"},
               "company":{"name":"Acme Co","email":"billing@acme.co"},
               "customer":{"name":"Jane Doe","email":"jane@example.com"},
               "item":{"description":"Consulting","amount":"$1,250.00"}}}'
```

`upload:false` returns base64 — decode it to confirm a valid PDF before wiring the live endpoint. Then flip to `upload:true`.

## Known gotchas (bake these in)

- **`printBackground: true`** or Tailwind backgrounds vanish in the PDF.
- **Fonts:** await `document.fonts.ready` / `networkidle0`, else text renders before web fonts load.
- **Rebuild CSS after editing templates** — the compiler only keeps classes it can see. `npm run dev` does this on watch.
- **Multi-page breaks:** use `break-inside-avoid` and `@page` rules in the template CSS.
- **Chromium in CI/sandbox:** the binary download can be blocked. `PUPPETEER_SKIP_DOWNLOAD=1` lets install finish; the render stage then needs a real Chromium at runtime.

## Deployment notes

- **Container:** bundle Chromium in the image — simplest.
- **Serverless (Lambda/Cloud Functions):** swap `puppeteer` for `puppeteer-core` + `@sparticuz/chromium`; the bundled Chromium exceeds the deploy size limit otherwise.
